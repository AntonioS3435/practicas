# Deep Learning — University Coursework

This repository contains the practical assignments completed during the **Deep Learning** course (3rd year) of the **BSc in Artificial Intelligence** at the University of A Coruña (UDC).

The assignments explore different neural network architectures, training techniques and evaluation methods, progressing from fully connected networks to convolutional, residual and recurrent architectures.

Each assignment was based on a problem statement provided by the course instructors. The corresponding Jupyter notebooks contain our implementations, experiments and analysis.

## Assignments

| Assignment | Topic | Description |
|---|---|---|
| **P1 — Neural Networks** | Fully Connected Networks | Image classification using dense neural networks, exploring overfitting and regularization techniques such as Dropout, L1/L2 and Batch Normalization. |
| **P2 — Convolutional Neural Networks** | CNNs | Implementation and experimentation with convolutional architectures for image classification. |
| **P3 — Residual Neural Networks** | ResNets & Transfer Learning | Implementation of residual architectures and fine-tuning experiments on CIFAR-10 using pretrained weights. |
| **P4 — Recurrent Neural Networks** | Time-Series Forecasting | EUR/USD exchange-rate prediction using MLP, LSTM, GRU and stacked recurrent architectures, including comparisons with baseline approaches. |

## Repository Structure

Each assignment directory generally includes:

- **Jupyter Notebook (`.ipynb`):** Implementation, experiments, results and discussion.
- **PDF (`.pdf`):** Original assignment instructions provided by the university instructors.
- **Additional files:** Datasets, model weights or other resources required by specific assignments.
